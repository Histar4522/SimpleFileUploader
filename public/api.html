API Example

1. GET /files/:filename

Download a file using its file uuid

Example: /files/875ec8d9-a512-436b-8d3f-adaa2122b7b7

Supported Parameters

  • attachment: boolean (default: false)

    Download the file as a attachment, usually trigger direct download


2. GET /files

Get all files stored

Example: /files

Result format

{[uuid]: {fileType: [MIME Type], filename: [Filename]}}

Example: {"875ec8d9-a512-436b-8d3f-adaa2122b7b7":{"contentType":"text/markdown","filename":"README.md"},"b5166d9c-8273-4969-badd-b00768d707a6":{"contentType":"text/plain","filename":"LICENSE.txt"}}


3. POST /files

Upload a file to storage

Example: /files?filename=image.png

Supported Parameters

  • filename: string (default: uuid of the file)

    Set the filename of the file. Will be shown when it is downloaded

Result format

{filename: [File UUID]}

Example: {"filename": "875ec8d9-a512-436b-8d3f-adaa2122b7b7"}


4. DELETE /files/:filename

Delete a file using its file uuid

Example: /files/875ec8d9-a512-436b-8d3f-adaa2122b7b7
